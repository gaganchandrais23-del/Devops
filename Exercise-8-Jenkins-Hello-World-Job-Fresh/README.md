# Exercise 8 - Jenkins Hello World Job

## Introduction
This project demonstrates how to create a basic Jenkins Freestyle job to execute a shell script.

## Objective
To understand how Jenkins runs shell commands and displays the build result.

## Tools Used
- Jenkins
- Bash
- GitHub

## Files
- `hello-world.sh` - Prints a Hello World message.
- `README.md` - Contains project documentation.

## Procedure
1. Create a shell script named `hello-world.sh`.
2. Add a command to print `Hello, Jenkins!`.
3. Create a Freestyle project in Jenkins.
4. Configure a build step to execute the script.
5. Run the job and verify the Console Output.

## Expected Output
    Hello, Jenkins!

The Jenkins build should finish with a SUCCESS status.

## Result
The Hello World shell script is prepared for execution through a Jenkins Freestyle job. This exercise introduces basic job configuration and shell script automation.
